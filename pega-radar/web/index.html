    Employer coverage

    Every employer on the original target list, how it is searched, and what happened the last time it was tried.

    How coverage works
    Portal
    An employer’s own careers site, or the hiring system behind it, that lists its jobs.
    Candidate
    A portal Pega Radar can read, taken from research, that nobody has yet checked against the live site. Shown as “unverified”.
    Inventory
    The list of employers and what is on file for each — separate from what happened when they were scanned.

    Configured is not attempted, and attempted is not successful. An employer is configured when a career portal Pega Radar can read is on file for it. It is attempted when a scan actually reached that portal. It is successful only when the portal answered completely (OK, or Empty when it has no Pega roles today).

    Verified portals were checked against the live site. Unverified (candidate) portals are implemented from research and are scanned — their results are real — but nobody has yet confirmed them live.

    Dashed labels are gaps in the inventory, not scan results: Not configured (no portal on file), Unsupported portal (it cannot be read without a browser), Wrong scope (the board does not cover India or this business), Identity unresolved (the listed name could not be matched to an employer). None of these is ever reported as Empty.

    The LinkedIn keyword query is a search for the word Pega plus the employer’s name. It is not a company filter and is never counted as coverage of that employer.

    To verify unverified portals: on your PC, open a command prompt in the pega-radar folder and run python radar.py verify. It makes a few small live checks per portal and writes a report to data/acceptance. Send the report file (data/acceptance/verify-….md) to whoever maintains your copy of Pega Radar; once it is agreed, python radar.py verify --promote marks the portals that passed as verified.

    Possibly closed on a role means every employer site or job board that listed it has re-read its full listing and no longer shows it. Roles seen only on LinkedIn are never flagged, and no role is ever deleted.
